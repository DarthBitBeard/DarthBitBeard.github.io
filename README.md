# Landon Beard, Resume Site

Personal resume site for Landon Beard, IT Specialist II with a cybersecurity focus.

Built with HTML and CSS, plus a small JavaScript file for scroll effects only: section reveals, a scroll progress bar, active navigation highlighting, and a subtle hero movement. No build step, no tracking, no phone number published.

## How to update

Edit `index.html` for content and `styles.css` for styling, then commit. GitHub Pages serves the site from the default branch.

Only security-related work an employer should see: the home OPNsense and AdGuard lab, including Hyper-V, Active Directory testing, monitoring, and the services hosted behind that protection, plus Hack The Box labs, and Folding@Home team leadership. Other projects, including Jellyfin work, are intentionally not listed as standalone projects here.
